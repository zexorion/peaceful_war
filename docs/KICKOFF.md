# KICKOFF — 30 دقيقة

> الهدف من الاجتماع: **يخرج كل واحد وهو عارف تاسكه + أول commit بيعمله بكره.**
> مش شرح كل حاجة. مش مراجعة كود. قرار وتوزيع.

---

## قبل الاجتماع (5 دقايق)

- [ ] الريبو مفتوح على الشاشة: `main.py` شغال قدامهم (مش صورة).
- [ ] `docs/TASKS_BRIEF.md` مفتوح في تبويب تاني.
- [ ] ورقة التوزيع (تحت) مطبوعة أو في note جاهز تكتب فيه.
- [ ] التأكد إن الـ Collaborators اتضافوا — لو لأ، قول في الأول وقول الحل.

---

## جدول الـ 30 دقيقة

| الوقت | إنت بتعمل إيه |
|---|---|
| **0–5** | شغّل اللعبة قدامهم. قول: "دي البداية مش اللعبة. الورقة والقلم شغالين، والباقي عليكم." |
| **5–10** | التاسكات الأربعة — **دقيقة واحدة لكل تاسك** من `TASKS_BRIEF.md`. مفيش تفاصيل تقنية. |
| **10–20** | **الاختيار.** كل اتنين يقولوا "إحنا تاسك رقم X". سجّل على طول. |
| **20–25** | القواعد الأربعة (تحت). وخصوصًا: branch مش main، ومفيش تعديل في فولدر حد تاني. |
| **25–30** | كل واحد يفتح الـ branch ويكتب أول commit — **قدامك، في الاجتماع**. |

> **أهم 10 دقايق في الاجتماع هي 10–20.** لو خرجت من غير توزيع، الاجتماع فشل حتى لو الشرح كان حلو.

## ورقة التوزيع

| Task | الفردين | Branch | جاهز؟ |
|---|---|---|---|
| 1 — أدوات الرسم | ____________ + ____________ | `task1-engine` | ☐ |
| 2 — الأرض والحفر | ____________ + ____________ | `task2-terrain` | ☐ |
| 3 — اللعبة والدمج | ____________ + ____________ | `task3-core` | ☐ |
| 4 — الشكل والتقرير | ____________ + ____________ | `task4-ui` | ☐ |

**قواعد التوزيع:**
- ممنوع تاسك من اتنين مبتدئين لوحدهم.
- **Task 3** لازم فيه حد قوي في الديباجنج — ده اللي بيدمج شغل الكل.
- **Task 4** ياخد حد تقني لو متاح (لازم يتعامل مع `config.py` والـ HUD).
- Task 1 ينضم لـ Task 3 بعد ما يخلص (يوم 5–6).

**لو حد غايب:** وزّعه مؤقتًا مع أقرب زوج، وارجع عدّل لما يجي. متسيبش تاسك من غير صاحب.

## القواعد الأربعة — قولهم بصوتك

1. **`core/canvas.py` و `core/display.py` ممنوع تتلمس.**
2. **ممنوع `pygame.draw` أو أي رسم جاهز** — كل بكسل بخوارزمية من الكتاب.
3. **مفيش شغل على `main`.** كل تاسك على branch، والدمج نهاية اليوم على مسؤولية Task 3.
4. **اللي واقف أكتر من ساعتين يسأل في الجروب** — وابعت نص الإيرور، مش صورة.

## بطاقات أول commit — وزّعها زي ما هي

### Task 1 — `task1-engine`
```bash
git checkout -b task1-engine
```
1. `line_direct` — الطريقة الساذجة `y = mx + b`.
2. `line_dda` — كامل، كل الـ octants.
3. **امسحوا `line_bresenham` من الريبو واكتبوها من الكتاب**، وبعدين قارنوا نتيجتكم بالنسخة القديمة.
4. تست لكل واحدة في `tests/test_lines.py`.

**خلصت لما:** `line_direct` + `line_dda` + `line_bresenham` بتاعتكم، والتستات خضراء.

---

### Task 2 — `task2-terrain`
```bash
git checkout -b task2-terrain
```
1. سكريبت صغير لوحده (مش في الريبو): Cubic Hermite بين 3 نقاط، اطبع/اعرض الناتج.
2. بعد ما تشوف المنحنى صح → انقله في `algo/curves.py`.
3. 5–7 نقاط تحكم عشوائية → `heights[]` بطول عرض الشاشة.

**خلصت لما:** عندك `heights[]` فيها رقم لكل عمود، ومنحنى Hermite بيوصل بين النقاط.

---

### Task 3 — `task3-core`
```bash
git checkout -b task3-core
```
1. آلة الحالات: `MENU → AIM → FLYING → BOOM → OVER` في `game/state.py`.
2. الإدخال: `←/→` زاوية · `↑/↓` قوة · `Space` إطلاق · `Esc` خروج.
3. اربطها في `main.py` — **من غير رسم جديد**، بس الحالة تتغير.

**خلصت لما:** تشغّل اللعبة وتشوف الحالة الحالية مكتوبة على الشاشة، والأزرار بتغيّرها.

---

### Task 4 — `task4-ui`
```bash
git checkout -b task4-ui
```
1. الـ palette في `config.py` (اتفق مع Task 3 قبل أي تعديل عليه).
2. **رسمة على ورق** لكل شاشة: البداية · اللعب · الفوز.
3. شاشة البداية الأولى — نص + شكل بسيط.

**خلصت لما:** شاشة بداية بتظهر، والـ palette كلها في `config.py`.
