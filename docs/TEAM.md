## 0. الفكرة في 30 ثانية

لعبة دبابات **دور ورا دور**: تظبط الزاوية والقوة، تطلق، القذيفة تنفجر، **تحفر الأرض**، وتنقص HP.
الشرط اللي بيتقيّم: **كل بكسل على الشاشة مكتوب بخوارزميات الكتاب** — ممنوع أي دالة رسم جاهزة.
8 أفراد = **4 تاسكات × فردين**.

## 1. الأساسيات الثابتة — ممنوع تعديلها

| الحاجة | القيمة |
|---|---|
| الأبعاد الداخلية | **640×360** (×2 نافذة = 1280×720 · `F11` ×3 = 1920×1080) |
| الشابترات | **2 · 3 · 4 · 5** (وفيه لمسات من 6 و7: قص الحدود + الدوران) |
| اللغة | Python 3.11+ |
| المكتبة | `pygame-ce` (بتتستورد كـ `pygame`) — نافذة/إدخال/توقيت/نص بس |
| الريبو | https://github.com/zexorion/peaceful_war |

### ملفات **متتلمسش خالص**
- `core/canvas.py` — الورقة والقلم (`set_pixel`). أي غلط فيها بيدفع تمنه المشروع كله.
- `core/display.py` — النافذة والتكبير والفولسكرين والنص.

### ملفات بتتعدل بحساب
- `core/util.py` — Task 1 يوسّعها لو محتاج، من غير ما يكسر التوقيعات.
- `config.py` — Task 3 بيديرها؛ أي رقم أو لون جديد بالاتفاق معاه.
- **قاعدة:** محتاج تغيير في ملف مش بتاعك؟ اطلبه في الجروب. متعدلوش.

> **ملحوظة:** الـ Canvas **مش UI**. الـ Canvas هو الورقة اللي بنرسم عليها. الـ UI هي الشاشات والـ HUD اللي بتترسم فوق الورقة دي.

## 2. اسحب المشروع

**ويندوز (PowerShell أو CMD):**
```bat
git clone https://github.com/zexorion/peaceful_war.git
cd peaceful_war
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

**لينكس / ماك:**
```bash
git clone https://github.com/zexorion/peaceful_war.git
cd peaceful_war
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

لو ظهرتلك نافذة فيها سما ليل ونجوم وتضاريس ودبابتين → إنت جاهز.
لو ظهرت رسالة `avx2` دي مجرد تحذير ومش مؤثرة.

**أوامر مساعدة (ويندوز):**
```bat
.venv\Scripts\python.exe main.py --shot out\slice0.png
.venv\Scripts\python.exe -m unittest discover -s tests -t .
```

## 4. إيه الموجود وإيه الناقص

اللي هتشوفوه اسمه **Slice 0** — ماكيت، مش لعبة.

| الحاجة | الحالة | مين هيستلمها |
|---|---|---|
| الشاشة + التكبير + الفولسكرين + النص | ✅ شغال | **متتلمسش** |
| `set_pixel` / الورقة (Canvas) | ✅ شغال | **متتلمسش** |
| خط Bresenham | ✅ شغال (مرجع) | Task 1 يمسحها ويكتبها بنفسه |
| تضاريس بـ `sin` | ⚠️ شكل مؤقت | Task 2 يشيلها ويحط Hermite |
| دبابة + نجوم + HUD نصي | ⚠️ شكل مبدئي | Task 4 يحسّنه |
| الدواير (القمر / الانفجار) | ❌ **مش موجودة عمدًا** | Task 1 |
| DDA والخط المنقّط | ❌ **مش موجود** | Task 1 |
| Hermite + التعبئة + الحفر | ❌ **مش موجود** | Task 2 |
| الفيزياء + الأدوار + الانفجار + الضرر | ❌ **مش موجود** | Task 3 |
| الشاشات + الـ Lab + التقرير | ❌ **مش موجود** | Task 4 |

> **ليه مفيش دايرة؟** عشان القمر وحلقات الانفجار وظل الدبابة كلهم دواير، ودي شغل Task 1.
> لو سيبنا نسخة جاهزة كانت هتتنسخ. فالماكيت فيه خط واحد وبس، والدايرة بتتضاف يوم 3–4.

## 5. التقسيم — 4 تاسكات × فردين

> **للاختيار السريع:** شوف [`docs/TASKS_BRIEF.md`](TASKS_BRIEF.md) — صفحة واحدة فيها الأربعة تاسكات باختصار.
> **قائد الفريق:** [`docs/KICKOFF.md`](KICKOFF.md) — أجندة 30 دقيقة + ورقة التوزيع + بطاقة أول commit لكل تاسك.

| Task | الشغل | الملفات | أول مهمة | الصعوبة |
|---|---|---|---|---|
| **1 — أدوات الرسم** | Direct · DDA · Bresenham · Midpoint Circle/Ellipse · Polar + الـ benchmark | `core/util.py` · `algo/lines.py` · `algo/circles.py` · `tests/` | اكتبوا Direct + DDA | ★★☆ |
| **2 — الأرض** | Hermite · توليد التضاريس · التعبئة · الحفر والـ refill | `algo/curves.py` · `algo/fill.py` · `world/terrain.py` | Hermite على 3 نقاط | ★★★ |
| **3 — اللعبة** | الحالات · الإدخال · الفيزياء · التصادم · الضرر · الأسلحة · **الدمج** | `main.py` · `game/` · `world/physics.py` · `world/weapons.py` · `world/tank.py` | آلة حالات + إدخال | ★★★ |
| **4 — الشكل والتقرير** | الألوان · الشاشات · الـ HUD · الـ Lab · التقرير · العرض | `ui/` · `assets/` · `docs/REPORT.md` | palette + رسم الشاشات | ★★☆ |

**مين ياخد إيه؟** كل واحد يجاوب لوحده:
1. مين أقوى واحد في الديباجنج والتنظيم؟ → **3**
2. مين أقوى في الرياضيات والمنحنيات؟ → **2**
3. مين لسه مبتدئ وبيحب خطوات واضحة؟ → **1**
4. مين بيحب التصميم والكتابة؟ → **4**

**قواعد:** ممنوع تاسك من اتنين مبتدئين لوحدهم · أحسن تركيبة قوي + مبتدئ · Task 4 ياخد حد تقني لو متاح · Task 1 ينضم لـ Task 3 بعد ما يخلص.

## 6. جولة واحدة — عشان تفهموا كل حاجة

1. اللاعب يضغط `←` → الزاوية تزيد → **Task 3** يحسب مكان الفوهة (**Task 1**: rotate) → **Task 1** يرسم خط منقّط (**DDA**) → **Task 4** يعرض الزاوية.
2. `Space` → **Task 3** يحسب السرعة ويطلع قذيفة → كل فريم الجاذبية والرياح تحرّكها.
3. القذيفة بترسم نفسها دايرة صغيرة → **Task 1** (Midpoint Circle).
4. تلمس الأرض → **Task 2** (`is_solid`).
5. انفجار: حلقات بتكبر (**Task 1**) + **Task 2** يشيل دايرة من الأرض ويعيد التلوين.
6. **Task 3** يوزّع الضرر → **Task 4** ينقص شريط الـ HP.
7. الدور يتبدل، والرياح تتغير → **Task 3**.

مفيش خطوة "سحر". كل خطوة ليها صاحب.

## 7. طريقة الشغل بـ Git

```bash
git checkout -b task1-engine     # أو task2-terrain / task3-core / task4-ui
```

- **ممنوع الشغل على `main` مباشرة.** كل حاجة على branch.
- **الـ Agent:** خلّيه يعدّل ويـ commit على الـ branch — **مش على `main`**، وميعملش push لـ `main`.
- commit بالشكل: `task2: terrain carve + refill`.
- **الدمج:** نهاية كل يوم. الـ Integration Lead (Task 3) هو اللي بيدمج.
- `main` لازم تشتغل دايمًا. أي merge بيكسرها يترجع فورًا.
- متعدّلش فولدر حد تاني. محتاج تغيير؟ اطلبه.

### هوية الـ commit — مرة واحدة بعد الـ clone

```bash
git config user.name  "اسمك"
git config user.email "إيميلك على GitHub"
```

من غيرها الكوميتات بتتسجل باسم حد تاني ومش بتتحسب لك في الريبو.
لو مش عارف الإيميل: GitHub → Settings → Emails → خد `…+username@users.noreply.github.com`.

**الـ push محتاج مفتاح SSH أو token** — الباسورد مش هينفع.
أسهل طريقة: GitHub Desktop، أو `gh auth login`، أو مفتاح SSH من Settings → SSH keys.

**كل يوم:** standup 10 دقايق — عملت إيه / هعمل إيه / واقف في إيه.

## 9. قواعد الكود

1. ممنوع `pygame.draw.*` · `gfxdraw` · `Surface.set_at` · `transform.rotate` · `smoothscale`.
2. ممنوع `import pygame` في `core/canvas.py` · `algo/*` · `world/terrain.py`.
