> **القاعدة:** كل تاسك بيكتب سطره هنا أول ما يخلص موديول. التقرير بيتجمع طول الأسبوعين، مش آخر يوم.
> كل خوارزمية: الفكرة في سطرين · التعقيد · فين بتظهر في اللعبة · لقطة.

## 1. الهدف

لعبة مدفعية turn-based، كل بكسل فيها بيتكتب بخوارزميات IT311. الهدف إثبات الفهم مش استخدام مكتبة رسم.

## 2. المعمارية

```
Input → Game Core (state: terrain, tanks, projectile)
      → Algorithms (pure modules: coordinates + color in, pixels out)
      → Canvas (bytearray + set_pixel)
      → Display (pygame: upscale + text)
```

- `Canvas` هي الطبقة الوحيدة اللي بتكتب بكسل.
- `algo/*` فيها صفر منطق لعبة ومفيش `import pygame`.
- الأداء: الخلفية بتترسم مرة وتتحفظ بـ `snapshot`، والتضاريس بتتعاد مرة واحدة بعد كل انفجار.

## 4. تفاصيل كل خوارزمية

### 4.1 — Direct line (line_direct) — Ch2
- **الفكرة:** رسم الخط بمعادلة $y = mx + b$ مع التبديل للمحور الأطول لتجنب الفجوات والقسمة على صفر.
- **التعقيد:** $O(\max(|dx|, |dy|))$
- **في اللعبة:** شاشة معمل الخوارزميات للمقارنة (Lab).
- **كتبها:** Task 1

### 4.2 — DDA line (line_dda & line_dda_dotted) — Ch2
- **الفكرة:** زيادة بمقدار خطوة ثابتة $dx/steps, dy/steps$ والتقريب في كل خطوة مع دعم التنقيط `gap`.
- **التعقيد:** $O(\max(|dx|, |dy|))$
- **في اللعبة:** مسار التصويب المنقط للمدفع ومعمل الخوارزميات.
- **كتبها:** Task 1

### 4.3 — Bresenham Line (line_bresenham) — Ch2
- **الفكرة:** قرار رقمي بأعداد صحيحة فقط بدون كسور أو ضرب، يغطي جميع الـ octants.
- **التعقيد:** $O(\max(|dx|, |dy|))$
- **في اللعبة:** مواسير المدافع، أشعة الليزر، إطارات المستطيلات والـ HUD.
- **كتبها:** Task 1

### 4.4 — Midpoint Circle & Disc (circle_midpoint & disc_midpoint) — Ch3
- **الفكرة:** تماثل ثماني (8-way symmetry) بمعامل قرار $d = 1 - r$، مع تعبئة أفقية للأقراص بـ `hline`.
- **التعقيد:** $O(r)$ لمحيط الدايرة، و $O(r^2)$ للقرص الممتلئ.
- **في اللعبة:** القمر في السماء، حلقات الانفجار المتوسعة، حفرة الانفجار.
- **كتبها:** Task 1

### 4.5 — Midpoint Ellipse (ellipse_midpoint) — Ch3
- **الفكرة:** تقسيم المنحنى لمنطقتين حسب زاوية الميل وتماثل رباعي (4-way symmetry) بأعداد صحيحة.
- **التعقيد:** $O(rx + ry)$
- **في اللعبة:** ظل الدبابة على الأرض وعناصر واجهة الـ HUD.
- **كتبها:** Task 1

### 4.6 — Polar Circle (circle_polar) — Ch3
- **الفكرة:** حساب النقط بالمعادلة القطبية $x = cx + r\cos\theta, y = cy + r\sin\theta$ بخطوة $1/r$.
- **التعقيد:** $O(r)$ (مع تكلفة إضافية لحساب الدوال المثلثية).
- **في اللعبة:** للمقارنة المعملية في شاشة الـ Lab فقط.
- **كتبها:** Task 1
