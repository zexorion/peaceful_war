## Task 1 — Engine & Primitives
**Canvas + Ch2 + Ch3 + تحويلات بسيطة** · الصعوبة ★★☆ · الوقت: 5–6 أيام

**أنت مسؤول عن:** `core/canvas.py` · `core/util.py` · `algo/lines.py` · `algo/circles.py` · `tests/`
**بتعتمد على:** مفيش. إنت أول واحد بيخلص.
**بيعتمد عليك:** كل التيم.

### هدفك
المحرك اللي كل حاجة بترسم من خلاله. لو إنت خلصت بدري، المشروع كله بيتحرك.

### أول 30 دقيقة
1. شغّل `main.py` وافهم ليه الشاشة بتظهر بالسرعة دي (الخلفية بتترسم مرة واحدة وتتحفظ بـ `snapshot`).
2. افتح `core/canvas.py` واقرأ الـ API.
3. شغّل التستات: `.venv/bin/python -m unittest discover -s tests -t .`

### الشغل بالترتيب
1. **Direct line** (`line_direct`) — القانون المباشر `y = mx + b`. بطيء ومش دقيق، وده المطلوب: هو المرجع اللي بنقارن بيه.
2. **DDA كامل** (`line_dda`) — نفس فكرة المنقّط بس من غير `gap`. لازم تدعم الميل العمودي.
3. **Bresenham** — موجود. راجعه، وضيف octants كاملة في التست.
4. **Midpoint Circle** (`circle_midpoint`) — 8-way symmetry. يستخدمه Task 3 في الانفجار و Task 4 في القمر.
5. **Midpoint Ellipse** (`ellipse_midpoint`) — لنفس الفكرة بس بـ rx, ry (ظل الدبابة وعناصر HUD).
6. **Polar** (`circle_polar`) — 10 دقايق، للمقارنة في الـ Lab.
7. **جدول الأداء:** دالة صغيرة `bench()` تقيس الأربع طرق (Direct / DDA / Bresenham / Polar) على نفس الخط والدايرة: عدد البكسلات + الزمن. النتيجة تتحفظ في `docs/REPORT.md`.
8. **تستات** لكل دالة جديدة (زي اللي موجودين في `tests/test_lines.py`).
9. بعد كده: انضم لـ Task 3 كتعزيز (أسلحة/تأثيرات).

### خلصت يعني
- [ ] `grep -rn "pygame" core/ algo/lines.py algo/circles.py` = صفر
- [ ] التستات كلها خضراء
- [ ] الخمس خوارزميات موجودة بنفس التوقيعات اللي في العقد
- [ ] الـ benchmark متسجل
- [ ] كل دالة ليها سطرين في `docs/REPORT.md`

### ممنوع
- `pygame.draw` / `set_at` / أي رسم جاهز.
- تحسب حاجة بالـ float في Bresenham (الميزة إنه integer).
- تعدّل `world/` أو `main.py`.

### لو اتأخرت
`circle_direct` و `disc_spans` موجودين كـ fallback شغال. سلّم الـ Midpoint بعديهم، ومش هتوقف حد.

## Task 2 — Terrain & Destruction
**Ch4 + Ch5** · الصعوبة ★★★ · الوقت: 6–7 أيام

**أنت مسؤول عن:** `algo/curves.py` · `algo/fill.py` · `world/terrain.py` · `tests/test_terrain.py`
**بتعتمد على:** `cv.hline` / `cv.vline` / `cv.set_pixel` (موجودين).
**بيعتمد عليك:** Task 3 (التصادم) و Task 4 (الشكل).

### هدفك
ده المشروع نفسه. التضاريس اللي بتتحفر وبتترسم من جديد هي الحاجة اللي هتقنع الدكتور.

### أول 30 دقيقة
1. افتح `world/terrain.py` — فيه تضاريس مؤقتة بـ `sin`. دي هتتشال.
2. جرّب `main.py --shot out/x.png` وشوف الشكل الحالي.
3. اقرأ Ch4 (Cubic Hermite) و Ch5 (Polygon fill) من الكتاب — هما أساس التاسك.

### الشغل بالترتيب
1. **Hermite** في `algo/curves.py`:
   `hermite(p0, p1, t0, t1, steps)` ترجع نقاط. جرّبها على 3 نقاط تحكم وارسمها بـ `line_bresenham` في سكريبت صغير.
2. **توليد التضاريس:** 6–8 نقاط تحكم موزعة على العرض + `hermite` بينهم → `heights[x]`. نفس الـ seed = نفس الخريطة (مهم للديباجنج).
3. **التعبئة:** نسخة سهلة: لكل عمود `x` اعمل `vline` من `heights[x]` لآخر الشاشة، مع تدرّج لوني بالعمق (ده scan-line بعمود واحد).
   النسخة الكاملة (general polygon fill) تتكتب بعد كده لو فيه وقت — التوقيع ثابت `fill_polygon(cv, points, color)`.
4. **الحد الخارجي:** خط rim بلون `TERRAIN_EDGE` على السطح — ده اللي بيدي الشكل المضيء.
5. **الحفر:** `carve(cx, cy, r)` تعدّل `heights` جوّه دايرة (استخدم `circle_direct`/`disc` كمرجع للشرط). بعدها إعادة رسم + `snapshot`.
6. **الـ refill الحيّ:** بعد الحفر، التضاريس تترسم تاني قدام اللاعب. متعملهاش كل فريم — مرة واحدة لكل انفجار.
7. **Stretch:** Bezier للصاروخ · Flood fill للمياه · Cohen–Sutherland.

### خلصت يعني
- [ ] `Terrain(seed=7)` بنفس الـ seed بيطلع نفس الخريطة
- [ ] `height_at` و `is_solid` شغالين وموثقين
- [ ] `carve` بيعمل حفرة حقيقية والتضاريس بتترسم تاني
- [ ] اللعبة لسه 60 FPS بعد الحفر
- [ ] تست: الحفر بيقلل الارتفاع في النص ومش بيلمس بره الدايرة

### ممنوع
- تحفظ التضاريس كصورة أو تلوّن يدوي.
- تعيد رسم التضاريس كل فريم (ده اللي هيقتل الأداء).
- `import pygame`.

### لو اتأخرت
الـ fallback هو تعبئة الأعمدة (`vline`) بدل الـ scan-line العام — نفس الشكل تقريبًا وأسهل بكتير. الـ Hermite مش قابل للاستبدال: من غيره مفيش Chapter 4.

## Task 3 — Game Core & Integration
**اللعبة + التجميع** · الصعوبة ★★★ · الوقت: طول المدة

**أنت مسؤول عن:** `main.py` · `game/` · `world/physics.py` · `world/weapons.py` · `world/tank.py`
**أنت كمان Integration Lead:** إنت اللي بتدمج الـ branches وتخلي `main` شغالة.

### هدفك
إن اللعبة تتلعب من أولها لآخرها، وإن شغل الـ 3 تاسكات التانية يبان على الشاشة.

### أول 30 دقيقة
1. شغّل `main.py` واقرأ `main.py` كله (300 سطر).
2. ارسم الـ state machine على ورقة: `menu → aim → flying → boom → (aim | over)`.
3. اعمل branch: `git checkout -b task3-core`.

### الشغل بالترتيب
1. **الـ loop والحالات:** حوّل `main.py` من "شاشة واحدة" لآلة حالات. الإدخال في مكان واحد.
2. **الدور:** لاعب 1 → لاعب 2. زاوية + قوة (←/→ للزاوية، Space مطوّل للقوة).
3. **الفيزياء:** `vx += wind*WIND_ACC`, `vy += GRAVITY`, ثم `x += vx`, `y += vy`. التصادم: `terrain.is_solid(x, y)`.
4. **الضرر:** المسافة من مركز الانفجار → ضرر خطي. HP + فوز/خسارة + إعادة.
5. **الانفجار:** 3 حلقات بتكبر (Task 1 circles) + `terrain.carve` + إعادة رسم.
6. **الأسلحة:** Shell (أساسي) + Laser (Bresenham فوري). الصاروخ لو Task 2 خلّص Bezier.
7. **التجميع:** نهاية كل يوم اعمل merge لكل الـ branches، وصلّح، واختبر `main`.

### خلصت يعني
- [ ] جولة كاملة: تصويب → إطلاق → انفجار → حفرة → ضرر → تبديل دور → فوز
- [ ] `R` بتعيد اللعبة من غير ما تقفل النافذة
- [ ] `main` على Git شغالة دايمًا
- [ ] كل الأرقام في `config.py`
- [ ] مفيش `pygame.draw`

### ممنوع
- تعدّل `algo/` أو `core/` — لو محتاج تغيير، اطلبه من صاحبه.
- تشتغل على `main` مباشرة.
- تدمج branch مش شغال.

### لو اتأخرت
الـ fallback: تضاريس مسطحة + انفجار بيكبر الـ HP بس (من غير حفر) — اللعبة تفضل قابلة للعب، والحفر يتضاف بعدين.

## Task 4 — UI/UX, Art & Delivery
**الشكل + الشاشات + التقرير** · الصعوبة ★★☆ · الوقت: طول المدة

**أنت مسؤول عن:** `ui/` · `assets/` · `docs/REPORT.md` · العرض والشرائح · اللقطات
**بتعتمد على:** Task 1 (الرسم) و Task 3 (القيم اللي بتعرضها).
**بيعتمد عليك:** مفيش — بس إنت اللي بتخلي المشروع يبان محترم.

### هدفك
إن اللعبة تبان *متعمدة* مش "شغّلنا الكود". وتجهيز التقرير طول الترم مش آخر أسبوع.

### أول 30 دقيقة
1. افتح `out/slice0.png` — دي نقطة البداية.
2. حدد palette نهائي في `config.py` (بالتنسيق مع Task 3).
3. ارسم wireframe لكل شاشة على ورق/Excalidraw.

### الشغل بالترتيب
1. **الهوية:** ألوان، سما، نجوم، قمر، rim light، شكل الدبابة. الستايل: ليل صحراوي، minimal، pixel.
2. **الشاشات:** Title (Play / How to play / Quit) · Pause · Game Over (الفايز + Play again).
3. **الـ HUD:** شريط HP (Bresenham + شرائح) · قوة · زاوية · رياح · السلاح · دور مين. كل ده بألوان وخطوط واضحة على 640×360.
4. **الـ Lab:** شاشة بتقارن Direct / DDA / Bresenham والدايرة Midpoint ضد Polar — بتعرض الزمن وعدد البكسلات. (البيانات من Task 1.)
5. **الـ juice:** screen shake (Task 3 بينفذها)، أرقام ضرر، وميض عند الإصابة، انتقالات بين الشاشات.
6. **التقرير:** ابدأ من يوم 1. لكل خوارزمية: الفكرة + التعقيد + فين بتظهر + لقطة. استخدم `docs/REPORT.md`.
7. **العرض:** شرائح + سكريبت ديمو 3 دقايق + جدول مساهمة.

### خلصت يعني
- [ ] كل شاشة ممكن توصلها من غير ما تقفل اللعبة
- [ ] الـ HUD مقروء على 640×360 (جرّبه على السطح النهائي)
- [ ] التقرير فيه كل الخوارزميات Core بلقطات
- [ ] العرض بيتلعب قدام حد من غير ما تشرح إنت
- [ ] جدول المساهمة جاهز

### ممنوع

### لو اتأخرت

- ممنوع تاسك من اتنين مبتدئين لوحدهم.
