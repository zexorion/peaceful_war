# Task 1 — Engine & Primitives
**Canvas + Ch2 + Ch3** · ★★☆ · 5–6 أيام

**الملفات:** `core/canvas.py` · `core/util.py` · `algo/lines.py` · `algo/circles.py` · `tests/`
**بيعتمد عليك:** الكل. **بتعتمد على:** مفيش.

### الهدف
المحرك اللي كل حاجة بترسم من خلاله: خطوط، دواير، وإحصاء أداء يثبت الفرق بين الخوارزميات.

### أول 30 دقيقة

3. شغّل التستات — هتلاقي Bresenham بس. الباقي عليك.

### المهام

**1.1 — Direct line** (`line_direct`)
القانون المباشر `y = m·x + b`. لو `|dx| >= |dy|` امشي على x، غير كده امشي على y (وإلا الخط هيبقى منقّط).
حالات لازم تتغطى: أفقي، رأسي، `dx=0`، القيم السالبة.

**1.2 — DDA** (`line_dda`)
`steps = max(|dx|, |dy|)`، بعدين `xinc = dx/steps`, `yinc = dy/steps`، و `round` في كل خطوة.
لازم يطلع نفس عدد بكسلات Bresenham تقريبًا — ده اللي هتقارن بيه في الـ Lab.

**1.3 — Bresenham** (موجود كمرجع)
موجودة في الريبو عشان الدبابات تبان من يوم 1 — **امسحوها واكتبوها من الكتاب بنفسكم**،
بعدين قارنوا نتيجتكم بالنسخة القديمة. لازم تغطي كل الـ octants، وعدد البكسلات =
`max(dx,dy)+1`، وعكس الاتجاه بيدي نفس البكسلات.

**1.4 — Midpoint Circle** (`circle_midpoint`)
`d = 1 - r`، بعدين `d += 2x+3` أو `d += 2(x-y)+5`، مع `plot8`.
اختياري مفيد: `disc_midpoint` (سطور أفقية من `-y` لـ `+y`) — القمر والانفجار محتاجينه.

**1.5 — Midpoint Ellipse** (`ellipse_midpoint`)
منطقتين: الأولى الميل > 1، التانية < 1.
`p1 = ry² - rx²·ry + 0.25·rx²`، وقف لما `2ry²x >= 2rx²y`، بعدين `p2` من النقطة اللي وقفت عندها.
الاستخدام: ظل الدبابة (ellipse مسطحة) وعناصر HUD.

**1.6 — Polar** (`circle_polar`)
`x = cx + r·cos θ`, `y = cy + r·sin θ`، و `θ += 1/r` (خطوة بحجم بكسل تقريبًا). للمقارنة بس.

**1.7 — Benchmark**
دالة واحدة `bench()` بتشغل كل نسخة 100 مرة على نفس المدخل وترجع: الاسم، عدد البكسلات، الزمن بالـ ms.
النتيجة تتحفظ في `docs/REPORT.md` قسم 5، وتتبعت لـ Task 4 يعرضها في الـ Lab.

**1.8 — Lab data API**
```python
lab_report() -> list[dict]   # [{"name": "Bresenham", "pixels": 401, "ms": 0.8}, ...]
```
Task 4 مش هيعرف يشغّل الـ algorithms بنفسه — إنت اللي بتوفر الأرقام.

**1.9 — تحسين**
اربط `set_pixel = cv.set_pixel` في متغير محلي جوه كل دالة (بيوفر lookup)، ومتحسبش حاجة جوه الـ loop تقدر تحسبها بره.

**1.10 — بعد ما تخلص:** انضم لـ Task 3 — حلقات الانفجار، الليزر، شريط الـ HP، وخط التصويب المنقّط.

# Task 2 — Terrain & Destruction
**Ch4 + Ch5** · ★★★ · 6–7 أيام

**الملفات:** `algo/curves.py` · `algo/fill.py` · `world/terrain.py` · `tests/test_terrain.py`
**بتعتمد على:** `cv.hline/vline/set_pixel` (جاهزين). **بيعتمد عليك:** Task 3 (التصادم) + Task 4 (الشكل).

### الهدف
التضاريس اللي بتتحفر وبتترسم من جديد بخوارزميتنا. ده المشهد اللي هيقنع الدكتور.

### أول 30 دقيقة
1. `world/terrain.py` فيه تضاريس مؤقتة بـ `sin` — دي هتتشال.
2. شوف `main.py::rebuild_background` — ده مسار إعادة الرسم بعد الحفر.
3. اقرأ Ch4 (Hermite) و Ch5 (Polygon fill) من الكتاب.

### المهام

**2.1 — Cubic Hermite** (`algo/curves.py`)
```
h00 = 2t³ - 3t² + 1      h10 = t³ - 2t² + t
h01 = -2t³ + 3t²         h11 = t³ - t²
P(t) = h00·P0 + h10·T0 + h01·P1 + h11·T1
```
`T0` و `T1` هما المشتقتين (المماسّين). للوصلة بين نقطتين استخدم أسلوب Catmull-Rom:
`T = (P[i+1] - P[i-1]) · 0.5`. ده بيدي استمرارية C1 — يعني مفيش كسر في المنحنى.
ترجع `list[(x, y)]` أعداد صحيحة.

**2.2 — نقاط التحكم**
6–8 نقاط موزعة بالتساوي على العرض، `y` بين 30% و75% من الارتفاع، من `random.Random(seed)`.
نفس الـ seed = نفس الخريطة بالحرف (مهم للديباجنج وللعرض).

**2.3 — بناء `heights[]`**
لكل وصلة: عيّن بعدد أعمدة الوصلة (عمود واحد لكل x) → `heights[x] = round(P(t))`، مع `clamp`.
لازم كل `x` من 0 لـ 639 يبقى ليه قيمة بالظبط.

**2.4 — الرسم**
لكل عمود: بكسل rim بلون `TERRAIN_EDGE` على السطح، بعدين `vline` لتحت بتدرّج 32 درجة (palette محسوبة مرة واحدة).
النتيجة: تل وفي شبه الصور المرجعية من غير أي صورة.

**2.5 — التعبئة**
- **الأساسي:** `fill_polygon(cv, points, color)` scan-line عام: polygon مقفول (السطح + القاع + الجانبين)، جدول حواف، تقاطعات، even-odd، سطر بسطر.
- **الـ fallback:** تعبئة بالأعمدة (`vline` من `heights[x]` لآخر الشاشة) — نفس الشكل تقريبًا وأسهل.
- **الـ gradient:** `vertical_gradient(cv, y0, y1, c0, c1)` — سطر واحد لكل y. (ده جوهر Gouraud بس في بعد واحد.)

**2.6 — الحفر** (`carve`)
```python
def carve(self, cx, cy, r) -> (x0, x1):
    for x in range(cx-r, cx+r+1):
        dy = sqrt(r*r - (x-cx)**2)
        if cy - dy <= self.heights[x]:          # الدايرة لمست السطح
            self.heights[x] = max(self.heights[x], cy + dy)
```
الفكرة: الأرض بتتشال جوّه الدايرة، فالسطح بينزل لقاع الدايرة. لو الدايرة كلها تحت السطح (كهف) — بنسيبها، لأن الـ heightmap مش بيمثل كهوف.
قصّ على `height-2` عشان مفيش عمود يختفي.

**2.7 — إعادة الرسم الحيّة**
بعد الحفر: `sky → terrain.render(cv) → snapshot`. موجودة في `main.py::rebuild_background`.
متعملهاش كل فريم — مرة واحدة لكل انفجار (~45ms).

**2.8 — Stretch:** Bezier للصاروخ · Flood fill للمياه · Cohen–Sutherland للقص.

- يوم 3–4: heights + تعبئة + rim.

### المهام

**3.1 — آلة الحالات**

**3.2 — الإدخال**

**3.3 — الدور والرياح**
`turn` (0/1)، رياح عشوائية كل دور (`-10..10`)، القوة ترجع للقيمة الافتراضية.

**3.4 — الدبابة على الأرض**
`y = terrain.height_at(x)`. الميل من العمودين المجاورين:
`tilt = degrees(atan2(h[x+3] - h[x-3], 6))`. المدفع child للدبابة: `muzzle = rotate_about(...)`.

**3.5 — التصويب + المعاينة**
الزاوية 0..180 (0 = يمين، 90 = فوق)، القوة 10..100.
**المعاينة المنقّطة:** شغّل نفس الفيزياء 60 خطوة من غير تصادم، وخد النقاط، وارسم بينها `line_dda_dotted` (بتاعة Task 1). ده القوس اللي في الصور — مش خط مستقيم.

**3.6 — الفيزياء**
```python
vx += wind * WIND_ACC
vy += GRAVITY
x  += vx
y  += vy
```
**مهم:** Velocity عالية = تخطي الأرض (tunneling). قسّم الحركة لخطوات 1px:
`n = max(1, ceil(max(abs(vx), abs(vy))))` ولف على `x += vx/n, y += vy/n` مع فحص التصادم كل خطوة.

**3.7 — التصادم**
`terrain.is_solid(x, y)` أو خروج من الشاشة. أول نقطة تصطدم = مركز الانفجار.

**3.8 — الانفجار**
3 حلقات بتكبر (Task 1) + `terrain.carve(cx, cy, 26)` + `rebuild_background` + اهتزاز الشاشة (offset على رسم العالم بس، مش على الـ HUD).
ضرر: `dmg = MAX_DMG * (1 - dist/radius)` لكل دبابة (بما فيهم اللي ضرب نفسه).

**3.9 — HP والفوز**
HP في الـ tank، `take_damage`، ولما يوصل صفر → `OVER` + الفايز + `R` تعيد.

**3.10 — الأسلحة**
`shell` (الافتراضي، ضرر + حفرة) · `laser` (شعاع فوري بـ Bresenham، بيقف عند أول أرض، ضرر أقل وبدون حفرة).
`Tab` بيبدل، والـ HUD بيعرض الاسم.

**3.11 — الدمج**

أي branch بيكسر `main` يترجع فورًا.
